# Sorting Visualizer

This project is a simple visualization of how different sorting algorithms work. I built it to better understand how sorting actually happens step by step, instead of just reading theory.

While working on this, I focused on making the process clear and easy to follow, especially how elements get compared and swapped during sorting.

## What this project shows
- How different sorting algorithms behave
- Step-by-step sorting process
- Comparison between algorithms

## Algorithms included
- Bubble Sort  
- Selection Sort  
- Merge Sort  

## Technologies used
- Python  
- Basic data structures and logic  

## Why I made this
Sorting is one of the most basic but important concepts in programming. I wanted to go beyond just writing code and actually see how it works in action.

## What I learned
This project helped me understand:
- Time complexity differences between algorithms  
- How optimization matters  
- How to break down problems into smaller steps  

## Output
The program shows how the list gets sorted step by step.

This is a learning-based project, but it gave me a strong foundation in understanding algorithms in a practical way.
